# 插图风格规范（FIGURE-STYLE）

> `learning/` 教程所有插图的统一规范。图用 draw.io 绘制，源文件与导出 PNG 都放在 `learning/Figures/`。

## 1. 文件与引用

- **存放位置**：`learning/Figures/`，源文件与导出图成对存在：
  - 源文件：`<章>-<节>-<主题>.drawio`（如 `ai-00-architecture.drawio`）
  - 导出图：同名 `.drawio.png`（内嵌 XML，用 draw.io 打开 PNG 即可继续编辑）
- **命名**：小写，连字符分隔；`<章>` 用包名缩写（ai / agent / tui / ca / srv），`<节>` 用两位数字
- **文档引用**：相对路径 Markdown 图片语法，图下不再重复标题（正文有引导句）：
  ```markdown
  ![pi-ai 分层架构](../Figures/ai-00-architecture.drawio.png)
  ```
- **导出命令**（在 `Figures/` 目录下）：
  ```powershell
  & "D:\software\draw\draw.io\draw.io.exe" -x -f png -e -b 10 -s 1.5 -o "名字.drawio.png" "名字.drawio"
  ```
  `-e` 内嵌 XML；`-b 10` 留边；`-s 1.5` 放大 1.5 倍保证文字清晰。

## 2. 字体

整体偏大，保证嵌入文档缩放后仍可读：

| 用途 | 字号 | 样式 |
|------|------|------|
| 图内大标题（尽量不用，正文已有引导句） | 20 | 加粗 |
| 层/容器标题 | 17 | 加粗 |
| 普通节点正文 | 15 | 常规 |
| 节点内次要说明 | 13 | 常规 |
| 边上的标注 | 13 | 灰色 `#666666` |

字体用 draw.io 默认（Helvetica），不指定特殊字体，避免跨机器渲染差异。

## 3. 配色（draw.io 默认调色板，固定语义）

| 语义 | 填充 | 描边 | 用于 |
|------|------|------|------|
| 调用方 / 上层 | `#dae8fc` | `#6c8ebf` | 蓝：外部调用者、入口 |
| 核心层 / 主流程 | `#d5e8d4` | `#82b366` | 绿：本图的主角组件 |
| 适配 / IO 层 | `#ffe6cc` | `#d79b00` | 橙：协议、网络、边界 |
| 数据 / 事件流 | `#f8cecc` | `#b85450` | 红：流、消息、产物 |
| 辅助数据 / 配置 | `#fff2cc` | `#d6b656` | 黄：旁路数据、存储 |
| 外部资源 / 第三方 | `#e1d5e7` | `#9673a6` | 紫：厂商、外部系统 |
| 中性容器内部 | `#ffffff` | 随容器 | 白：容器内的子块 |

同一语义在所有图中颜色一致（例如"事件流"在任何图里都是红色）。

## 4. 形状与连线

- **节点**：圆角矩形（`rounded=1`），一图内宽度尽量统一
- **主流程连线**：实线正交（`edgeStyle=orthogonalEdgeStyle;rounded=1`），箭头默认
- **旁路/引用连线**：虚线（`dashed=1`），表示"使用/参考"而非数据流
- **边标注**：独立文本节点或边 label，13 号灰字，说明"这条线上传的是什么"
- **布局方向**：调用/数据流自上而下；依赖关系图自下而上（被依赖者在下）
- 一张图一个主题，节点数控制在 12 个以内；更复杂的拆成两张

## 5. 内容原则

- 图是正文的**配角**：正文的引导句说明看什么，图只负责结构关系，不堆长句
- 节点文字 ≤ 3 行；机制细节留给正文，图内只写名词短语
- 中文为主，代码标识符保留英文原样（`streamSimple`、`Model`）
- 不加水印、不加作者、不加日期
